### 👋 Sobre mim

Sou desenvolvedor full-stack e transformo ideias em produtos que vão para produção: de sites institucionais e e-commerces a plataformas de gestão pública, sistemas jurídicos com IA e automações para redes sociais.

- 🚀 Construo sistemas completos: front-end, back-end, banco de dados e deploy
- 🤖 Integro IA, pagamentos, emissão de nota fiscal e APIs de terceiros (Meta, Google, TikTok)
- 🏛️ Desenvolvo soluções para gestão municipal, RH, estoque e privacidade de dados (LGPD)
- 📚 Sempre estudando — alguns projetos de curso estão públicos aqui no perfil
